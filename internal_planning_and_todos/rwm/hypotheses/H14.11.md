# H14.11 — Serve-consistency constraint (lesson promoted to a design rule)

**Claim (confirmed failure mode):** an encoder conditioned at train time on a statistic the policy
server cannot compute causally at rollout produces ω that no serve convention reproduces; the
resulting policy arms are non-evaluable. **Rule:** train-time conditioning must be a statistic the
server computes causally at rollout — check before training any conditioned model.

**Origin:** status §25.5–25.8 (2026-09-01/02), found pre-rollout by the D7 parity gate.

**Evidence:**

| item | result |
|---|---|
| Stage-E `lang_global` | non-causal whole-episode mean of the language embedding |
| trunk sensitivity | amplifies off-manifold lang deviations 30–80× |
| serve conventions tried | running-mean fails P1/P2/P3; task-mean passes only P3; none passes the bars (median ≥0.99 / p05 ≥0.95 / none <0.90) |
| consequence | rmb P1/P2/P3 (trained 2026-09-01) retired NON-EVALUABLE; no number from them may enter a table |
| fix | serve-consistent conditioning: `task_mean` for robocasa/rmb/robomme, per-frame subtask instruction for robocerebra; D7 parity must use `--lang-mode stored` (a recomputed task mean fails a correct encoder); `encoder_step` recorded in the ω store and checked |

**Side finding (paper-relevant):** under serve-time lang the structure-free ctrl-0b ω moved
(20 % of demos below cos 0.90, some orthogonal) while E1b barely moved (p05 0.98) → ctrl-0b's ω is
prompt-dominated (60 % interaction); the deliberative term grounds ω in vision (VISION share 54–58 %
vs 27 %). Attribution scope (§25.5a): term-presence-specific, positive-source-generic, measured on
the rmb multi-domain cells only.

**Status:** CONFIRMED as failure mode; rule banked in memory and PROTOCOL. No open experiment.
**Last sealed:** 2026-09-02.
